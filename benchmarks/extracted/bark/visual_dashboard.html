التدفق الأول: إقران جهاز الطفل برمز الاستجابة السريعة (QR Code Pairing)

يقوم الوالد بإنشاء ملف تعريف للطفل عبر مسار /children، ثم يختار نوع الجهاز (Android / iOS / Chromebook). يولد الخادم رمز QR ديناميكياً مشفراً يحتوي على: AccountToken + ChildProfileID + PairNonce، بالإضافة إلى رمز رقمي بديل (مثال: BRK-8924) صالح لمدة 15 دقيقة. عند مسح الرمز بكاميرا هاتف الطفل، يتم تبادل مفاتيح AES-256 محلياً وتثبيت الاقتران.

التدفق الثاني: معالج تفعيل الأذونات التراكمي (Progressive Permission Onboarding)

لتفادي رفض المستخدم للأذونات الحساسة دفعة واحدة، صممت Bark معالجاً تدريجياً يشرح أهمية كل إذن قبل طلبه برمجياً: 1. تفعيل Accessibility Service لرصد نصوص محادثات الشبكات الاجتماعية. 2. تفعيل Notification Listener Service لالتقاط الرسائل قبل مسحها. 3. تفعيل VpnService لتشغيل محرك Bark Guard Loopback DNS. 4. تفعيل Device Admin & Usage Stats لمنع حذف التطبيق.
