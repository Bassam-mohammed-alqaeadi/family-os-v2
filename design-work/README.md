# Design Work

This directory is the dedicated workspace for Family OS design work on `feat/governance-v2`.

## Scope

- Keep design deliverables and working documents created for the design phase here.
- Preserve existing governance specifications and approved design-system source files; do not duplicate or silently rewrite them here.
- Trace each design artifact to its governing requirement, system, screen, and source document.
- Record unresolved behavior or missing decisions as `UNKNOWN` for owner review; do not invent product rules.
- Separate proposed design decisions from approved decisions.
- Record asset provenance and usage rights before reusing any extracted asset.

## Working rule

This workspace does not authorize changes to application code, existing governance documents, or the established design system. Such changes require explicit review and approval.


## Current S1-01 design direction

See [S1-01 Design Workbench](S1-01/README.md). The new platform experience foundation and interactive studio are the current exploratory direction. Earlier S1-01 wireframes and screen compositions are retained for audit/history, not as the visual template for the new design.
