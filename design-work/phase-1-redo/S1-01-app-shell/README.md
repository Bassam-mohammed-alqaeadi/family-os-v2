## لماذا أُعيد العمل

رفض المالك النموذج السابق وطلب إعادته بدقة وصرامة دون الاعتماد على خطة الشاشات. لذلك:

- لم تُستعمل قوائم الشاشات في SPEC §9 (حالتها «مسودة») ولا تركيب النموذج السابق.
- كل سطح هنا مشتق من SPEC §1–§8 المعتمدة، وسجل القرارات، ونظام التصميم المعتمد.
- كل بند يحمل وسماً: **معتمد** (بمصدره) · **مشتق** · **مقترح** · **UNKNOWN**.
- ما لا يملكه S1-01 لا يُرسم: تبويبات الأنظمة الأخرى تعرض إطار ملكية يسمّي نظامها المالك.

## التشغيل

افتح `index.html` مباشرة، أو:

```bash
cd design-work/phase-1-redo/S1-01-app-shell && python3 -m http.server 8000 --bind 0.0.0.0
```

الرقم السري التجريبي لبوابة الوالدين: `246810`.
