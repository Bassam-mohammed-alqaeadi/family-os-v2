# الخطة العملية الليلية — سير العمل والتحقق والنقد والتصميم

> **أمر المالك 2026-11-07 (من المحادثة الجانبية):** الفريق البرمجي يعمل ليلاً بشكل مستمر — يكمل خطة الإصلاح (المرحلتان 3 و4) ثم مرحلة التصميم كاملة باحترافية، **ويتوقف بعد اكتمال التصميم**. المالك يراجع العمل غداً صباحاً ويتحقق من جودته. لا بناء ولا كود ميزات في هذه المهمة (G-003 / G-012).

## 2. حلقة العمل لكل بند (لا يُتخطى أي خطوة)

1. **تحقيق** (قراءة فقط): تثبيت المراسي حرفياً — النص القديم + المصدر الحاكم (REQ / قرار / عقد).
2. **اقتراح**: النص الجديد + سببه + مصدره.
3. **تطبيق**: تعديل واحد في كل مرة، بمالك واحد للملف.
4. **تحقق**: grep بعد التطبيق + فاحص Mermaid + الأعداد (المفاتيح 82) + الروابط الداخلية.
5. **نقد مستقل**: مراجع ثانٍ يعيد الفحص من الصفر ويكتب ما وجده — لا يُدفع ما لم يمر النقد.
6. **إصلاح** ما وجده النقد، ثم **إعادة تحقق**.
7. **دفع**، ثم **تحقق من رأس الفرع** بعد الدفع.

## 3. قواعد ملزمة

- **لا حكم يواجه المالك يُحسم ليلاً.** أي خيار (أ/ب) يخص المالك — مثل «منتصف الليل» وحقل الدليل وبنود المرحلة 3 المعلقة — يُجهَّز كبطاقة للصباح، ولا يُنفَّذ. التقني (Juno والفريق) يُحسم داخلياً فقط.
- **لا رقم ولا تاريخ ولا عدد يُخترع.** كل تغيير يستشهد بمصدره (REQ / قرار / عقد / RE). ما لا مصدر له يُسجَّل فجوة، لا يُملأ تخميناً.
- **إعادة مزامنة قبل كل تعديل ودفع.** ملف واحد لمالك واحد في كل لحظة؛ لا تعديلان متوازيان على الملف نفسه (درس حادثة G-012 وتداخل Q-172).
- **Mermaid:** اقتباس كل تسمية تحوي `(` أو `)` أو `{` أو `}` (`-->|"..."|` / `V["..."]`)؛ الفاحص يجب أن يعطي 100% قبل كل دفع.
- **الأعداد:** سجل المفاتيح الموحد 82 — أي تغيير فيه يُحدَّث في السجل وفي كل §10 معني.
- **التناسق عبر المراحل (جوهر المهمة):** كل عنصر تصميم يتتبع إلى REQ في المواصفة، وكل REQ إلى قرار أو استخلاص RE. أي عدم تطابق (تحليل ↔ تخطيط ↔ تصميم) يُسجَّل كفجوة ويُصلح إن كان تقنياً، أو يُرفع بطاقة للصباح إن كان حكماً.
- **لا بناء ليلاً.** الهيكل الفارغ + CI الحي (AUD-016/017) هو الاستثناء الوحيد المسموح. مرحلة التصميم هي نهاية المهمة.

## 4. الأدوار

- **منسق**: يوزع البنود، يمنع تداخل الملفات، يجمع النتائج، يدفع.
- **محققون** (قراءة فقط): يثبتون المراسي والمصادر — لا يعدّلون شيئاً.
- **منفذون**: يطبقون بنداً واحداً في كل مرة.
- **مراجع مستقل (نقد)**: يعيد فحص كل دفعة قبل دفعها — ويحق له إيقاف الدفع.

## 5. التوقف والتسليم (صباحاً)

بعد اكتمال التصميم + التحقق + الدفع **يتوقف الفريق** — لا يبدأ تنفيذ كود ولا مواصفات مرحلة 2. تقرير الصباح (في المحادثة الرئيسية) يحوي:

- ما تم — بالـcommits وأرقام الفحوص (Mermaid / الأعداد / الروابط / CI).
- ما ينتظر حكم المالك — البطاقات جاهزة واحدة واحدة.
- الفجوات المتبقية — إن وُجدت، مع مصدر كل فجوة.
- أدلة الجودة — لا ادعاء بلا دليل مفحوص.
