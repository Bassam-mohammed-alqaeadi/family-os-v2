# الخارطة التخطيطية — Family OS

> **الحالة:** مسودة تخطيطية · **التاريخ:** 2026-11-04
> **تنبيه:** هذه وثيقة **تخطيط** — لا تعني بدء التنفيذ. التنفيذ لا يبدأ إلا باكتمال الحوكمة وقرار صريح من المالك (G-003).
> **القرارات الحاكمة:** Q-001 (Kotlin/Ktor + PostgreSQL) · Q-002 (نواة الحماية أولاً)

## المبدأ الحاكم للترتيب

**المخاطرة أولاً:** أعلى مخاطرة تقنية تُخطط لها وتُثبت أولاً، وما بعدها أسهل. لا يُبنى واسعاً قبل إثبات العميق.

## المراحل

### المرحلة 0 — الحوكمة (الحالية)
- **الهدف:** حوكمة كاملة + كل الفئة (أ) محسومة + مراجعة المالك.
- **المخرج:** بوابة G1 → الدمج في `main`.

### المرحلة 1 — نواة الحماية (Q-002)
- **الهدف تخطيطياً:** إثبات أصعب جزء — التنفيذ على جهاز الطفل.
- **المكونات:** تطبيق طفل أندرويد (Kotlin: DeviceAdmin + Accessibility + VPN) · خادم Ktor (قواعد + جداول bitmask الأسبوعية) · لوحة أهل Flutter · الإقران برمز الجهاز · أوامر FCM بتوقيع HMAC · قناة MQTT بديلة (للأجهزة بلا GMS).
- **المخرج:** بوابة G2/G3.

### المرحلة 2 — التواصل العائلي
- **الهدف:** مراسلة مُدارة افتراضياً (D-019) بمزامنة الفروق على نمط تيليجرام، جاهزية E2E للبالغين لاحقاً.
- **أولوية ملزمة (Q-063):** تبديل الملفات على جهاز مشترك (هدف < 250ms) — لأن سوق الإطلاق (اليمن) تشارك الأجهزة؛ يُنفَّذ في هذه المرحلة قبل توسيع النطاق.
- **المخرج:** بوابة G2/G3.

### المرحلة 3 — التعليم
- **الهدف:** أوضاع الدراسة الـ 12 + محرك FSRS-4.5 خادمياً (عقد Quizlet منسوخ حرفياً).
- **المخرج:** بوابة G2/G3.

### المرحلة 4 — الخدمات الدينية
- **الهدف:** محرك الأذان الفلكي على الجهاز (22 طريقة حساب) + القبلة + القرآن (مصادر مفتوحة).
- **المخرج:** بوابة G2/G3.

### المرحلة 5 — التنسيق العائلي
- **الهدف:** القوائم والتقويم والمهام (FamilyWall) + الموقع والأسوار الجغرافية (SOS مبكراً per D-025).
- **المخرج:** بوابة G2/G3.

### المرحلة 6 — طبقة الذكاء الكاملة
- **الهدف:** تفعيل الميزات على بنية `ai-gateway` (D-029) + نماذج ONNX على الجهاز (سابقة Bark Kids) + وكيل الأب بحدوده المعتمدة (Q-003).
- **المخرج:** بوابة G2/G3.

### المرحلة 7 — التصليب والإطلاق
- **الهدف:** معيار الـ 10M (معمارية: stateless + read replicas + sharding حسب `family_id`) · مراجعة سياسات المتاجر · مراجعة قانونية/شرعية · خطة التراجع.
- **المخرج:** بوابة G4 → الإطلاق (اليمن ودول الخليج معاً per Q-005؛ البنية مهيأة للعالمية).

## ما بعد الخارطة

- تفصيل كل مرحلة إلى مواصفات أنظمة (قالب `templates/system-spec.md`) يأتي **بعد** اكتمال الحوكمة.
- ترقيم الأنظمة القديم (S1-01…) يُعاد تقييمه مع Q-002 — لا يُعتمد حتى يُراجع.
