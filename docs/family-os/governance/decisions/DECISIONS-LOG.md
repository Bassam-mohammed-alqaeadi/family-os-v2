# سجل القرارات الموحد — Family OS

> **المرجع الأعلى بعد الميثاق.** إن تعارض أي ملف مع قرار هنا فالقرار هو الصحيح.

> **المصدر:** مُستخلص من سجل الفرع السابق (`spec/99-decisions/decision-log.md`) بعد التصفية — ما ثبت صحته نُقل، وما تعارض أُعيد حسمه، وما كان شبحياً أُلغي.
