| G-002 | قاعدة "لا عناصر نائبة": لا يدخل الفرع الجديد إلا الجاهز المحسوم؛ المفتوح يُسجَّل بمالك وتاريخ قرار. | درس الفرع السابق. (أمر المالك 2026-11-04) |
| G-003 | التسلسل: اكتمال الحوكمة كاملة أولاً، ثم يُقرر كتابة كود المرحلة 1. لا كود قبل الحوكمة. | (أمر المالك 2026-11-04) |
| G-004 | Juno قائد العملية التقنية بتفويض تصحيح صريح بلا مجاملة. | (أمر المالك 2026-11-04) |

| G-006 | مبدأ الشفافية: سياسة شفافية كالتطبيقات الكبرى (إشعار دائم + موافقة + عدم إخفاء) **بتصميم غير مزعج** — مفيد لا منبّه. | (أمر المالك 2026-11-04) |
| G-007 | مجموعة مزايا "Play-safe": جداول + حظر تطبيقات + فلترة VPN + موقع + تقارير — **بدون قراءة محتوى SMS**. | بحث سياسات المتاجر Q-026: قراءة محتوى الرسائل هي منطقة الخطر (سبب إزالة Bark Kids). (مقترح — بانتظار اعتماد المالك) |
| G-008 | قاعدة "لا مستقبل بلا سجل": كل ما يُذكر في النقاش بصيغة "لاحقاً/في المستقبل" **يُسجَّل فوراً في الحوكمة** — سؤال مفتوح بمالك وتاريخ، أو عنصر خارطة، أو بند قرار — لا شيء مستقبلي يبقى في المحادثة فقط. | (أمر المالك 2026-11-04: الأشياء التي نقول سنعملها في المستقبل يجب أن تُسجَّل في المستودع كي لا ننسى توثيقها) |
