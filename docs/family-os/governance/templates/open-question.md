# قالب: سؤال مفتوح

```markdown
## [Q-المعرّف]: [السؤال]
- **الحالة:** مفتوح / بانتظار بحث / مُرحَّل / محسوم
- **التاريخ:** YYYY-MM-DD · **المالك:** (اسم)
- **تاريخ القرار المستهدف:** YYYY-MM-DD
- **السؤال:** (صيغة دقيقة)
- **لماذا يمنع:** (ما الذي يتوقف عليه)
- **الخيار المؤقت (إن وُجد):** + السبب
- **الحكم:** (يُملأ عند الحسم + التاريخ)
```

القاعدة (G-002): لا شيء بين المحسوم والمُدار — كل مفتوح هنا له مالك وتاريخ.
