# قالب: بوابة مراجعة

```markdown
## مراجعة بوابة [G-N]: [اسم المرحلة/النظام]
- **التاريخ:** YYYY-MM-DD · **المراجعون:** المالك + القائد التقني

### قائمة الفحص
- [ ] كل البنود في QUALITY-GATES.md §4 مستوفاة
- [ ] الاختبارات: [عدد] كلها ناجحة (سجل مرفق)
- [ ] لا TODO/FIXME ولا بيانات وهمية في مسار الإنتاج
- [ ] فحص الأمان والصلاحيات مكتمل
- [ ] مراجعة سياسات المتاجر (للإصدارات)
- [ ] التوثيق محدّث (الحالة + القرارات + الأسئلة)

### القرار
- [ ] مغلقة — الحالة: verified
- [ ] مفتوحة — النواقص: ...

### توقيع المالك: ____
```

لا إغلاق ذاتي للبوابات أبداً.
