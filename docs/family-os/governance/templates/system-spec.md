# قالب: مواصفة نظام

```markdown
# [S-المعرّف]: [اسم النظام]
- **الحالة:** drafted | approved | implemented | verified
- **المرحلة:** N · **آخر تحديث:** YYYY-MM-DD
- **القرارات الحاكمة:** (معرفات من DECISIONS-LOG)
- **الأدلة المرجعية:** (VERIFIED + المسار في deep-dives/inventories)

## 1. الهدف والنطاق
(فقرة واحدة: ماذا يفعل وما لا يفعل)

## 2. المتطلبات الوظيفية
- REQ-001: ... (كل متطلب: معرف + صيغة قابلة للاختبار + مستوى الثقة)

## 3. الواجهات والعقود
(نقاط الوصول/الأحداث/الأخطاء — بالإنجليزية تقنياً)

## 4. البيانات
(الجداول/الحقول — كل جدول يحمل family_id per D-021)

## 5. الصلاحيات
(مفاتيح domain.action + الثوابت الصلبة)

## 6. الحالات الحدية والأخطاء
(بلا اتصال، فشل، تعارض — مع سلوك التعافي)

## 7. معايير القبول
- ACC-001: ... (كل معيار مرتبط باختبار آلي لاحقاً)
```

**ممنوع:** الاختصار (`...`/`إلخ`)، الأقسام الفارغة بصمت (تُحال لسؤال مفتوح)، النصوص التقنية بالعربية.
