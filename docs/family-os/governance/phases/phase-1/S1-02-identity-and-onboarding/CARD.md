## 1. الهدف والنطاق (مقترح)

**ماذا يفعل هذا النظام؟**
هو نقطة البداية الحقيقية لكل مستخدم: تسجيل الدخول برقم الهاتف وOTP، إنشاء العائلة وتسميتها، انضمام البالغين بدعوة، إنشاء ملفات الأطفال (بلا بيانات اتصال)، واقتران أجهزة الأطفال — مع موافقة مشتركة (أب + طفل) مرة واحدة.

**داخل النطاق:**
- تسجيل الدخول: رقم هاتف + OTP عبر الموجّه (WhatsApp أولاً → SMS مجمّع → مكالمة فائتة) + TOTP داخل التطبيق بعد أول تحقق (Q-021).
- الجلسات: Access Token + Refresh Token بدوران آمن.
- إنشاء العائلة: التسمية + اختيار المنطقة (`region`)؛ رموز الدعوة تتولد عشوائياً لكل طلب انضمام (استخدام واحد، 7 أيام — Q-076)، لا رمز عائلي واحد عند الإنشاء.
- انضمام البالغين: رمز دعوة (وروابط عميقة — سؤال أدناه).
- ملفات الأطفال: ينشئها الأب/المفوَّض فقط (D-006)؛ بلا بيانات اتصال؛ اسم مستعار + صورة رمزية + لون + سنة ميلاد لتحديد قالب العرض.
- اقتران أجهزة الأطفال: رمز جهاز (سؤال أدناه)؛ شهادة جهاز؛ تحديد الوضع (Q-062).
- الموافقة المشتركة: إعداد مشترك (أب + طفل) مرة واحدة — شفافية عن الفئات لا المحتوى (G-006/D-023).
- فتح سريع بالبصمة/الوجه للأهل (سؤال أدناه) — لا يتجاوز بوابة الوالدين أبداً.

**خارج النطاق (أنظمة أخرى):**
- محرك تقييم الصلاحيات وتفويضها (نظام الأدوار والصلاحيات).
- محرك الفرض وشاشات الحظر (نظام الحماية).
- الخطط والدفع (نظام الفوترة).
- تبديل الملفات (مؤجل للمرحلة 2 — أولوية، Q-063).

## ملاحظة ما بعد البطاقة — أحكام صدرت بعد اعتماد البطاقة (2026-11-05) ونُفذت في المواصفة

- **Q-076 (رموز الدعوة):** رمز الدعوة عشوائي يتولد لكل طلب انضمام؛ استخدام واحد؛ صالح 7 أيام؛ المالك يلغي أي رمز معلق — في المواصفة REQ-009/REQ-010 (لا رمز عائلي واحد عند الإنشاء).
