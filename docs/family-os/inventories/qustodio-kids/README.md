# ملف إرشادات وتوثيق جرد تطبيق Qustodio Kids — عائلتي (Family OS)

> **معرّف التطبيق:** `qustodio-kids`
> **الحزمة المفحوصة:** `com.qustodio.qustodioapp` (تطبيق الطفل / Kids App)، الإصدار 680.78.1.2-family
> **البنية المعمارية:** وكيل إنفاذ أحادي التطبيق (Single-App Child Enforcement Agent) — إنفاذ ثلاثي المكدّس: DeviceAdmin + AccessibilityService + VPN أصلي (QProxy)
> **المرحلة:** سلسلة التوثيق العميق للخطة الموحدة #4 (Unified-Plan deep-doc series #4)
> **حالة الاعتماد:** مكتمل ومحقق — ثالث جرد لتطبيق طفل في البرنامج (بعد FamiSafe Jr وBark Kids)، والأقوى تقنياً بينها 🎯

> **فخر هذا الجرد:** تقرير الجولة الأولى (`docs/family-os/reports/qustodio.md`) غطى تطبيق الأهل وحده
> (Cordova/React) وانتهى عند «التنفيذ على جهاز الطفل تخمين مرفوض». هذا الجرد **يغلق تلك الفجوة**:
> أول تحليل على الإطلاق لتطبيق الطفل `com.qustodio.qustodioapp` — حيث يعيش الإنفاذ الحقيقي:
> مستقبل DeviceAdmin (مرساة مضادة للإلغاء بلا سياسات)، أنبوب accessibility كامل (29 محللاً)،
> محرك قرارات حظر سباعي، وVPN أصلي (QProxy/MITM) — كلها موثقة بأسماء كلاسات ومسارات دقيقة.

## 1. الفهرس والوثائق الهندسية المعتمدة في مجلد التحليل (`analysis/`)

تستقر كافة وثائق التحليل الهندسي المعمق في مجلد [`analysis/`](./analysis/) وفق المعيار المعماري الموحد لبرنامج BIP:

- **وثيقة الاستكشاف الوظيفي وتحليل الفجوات:** [`analysis/COVERAGE-AND-GAPS.md`](./analysis/COVERAGE-AND-GAPS.md)
  - تغطية 40 وظيفة تفصيلية موزعة عبر 10 مجالات وظيفية:
    - **31 وظيفة مؤكدة بالكود (Confirmed — Level A):** المكدّس الثلاثي، الأنبوب الكامل، قرارات الحظر، QProxy، الأوامر السبع، المراقبة، الإبقاء الحي.
    - **4 وظائف مشتقة (Derived — Level B):** وحدات الحصص، دلالة `action`، تغذية محرك الملاحة، سياسة إعادة اتصال الـ VPN.
    - **3 وظائف جزئية (Partial):** عناوين API (الإعداد مشفّر)، view-ID الكاشطات لكل نسخة، فك تشفير qinit.
    - **2 وظيفة غير موجودة (Not Found):** ذكاء اصطناعي على الجهاز (صفر)؛ WebSocket دائم.
- **تقرير التشريح البنيوي والمكونات (T1):** [`analysis/T1-STRUCTURAL-REPORT.md`](./analysis/T1-STRUCTURAL-REPORT.md)
  - تشريح الـ Manifest (307 أسطر: الخدمات الثلاث الكبرى + SMS/مكالمات بأولوية قصوى + زر ذعر + إقلاع) و40+ صلاحية.
  - حصر المكوّنات: 29 محلل accessibility، 7 قرارات حظر، 7 أوامر FCM، 19 مورداً معمارياً.
- **خريطة الموارد المعمارية (T2):** [`analysis/T2-RESOURCE-MAP.md`](./analysis/T2-RESOURCE-MAP.md)
  - توثيق 19 مورداً معمارياً ووظيفياً من `QUK-RES-000001` إلى `QUK-RES-000019` + 16 علاقة بينية (`REL-000600` إلى `REL-000615`).
- **التحليلات الهندسية المعمقة (T3):** [`analysis/T3-ENGINEERING-DEEP-DIVES.md`](./analysis/T3-ENGINEERING-DEEP-DIVES.md)
  - المسار A: تشريح QProxy الأصلي (JNI/JNA، HTTP/2، MITM، صفحة الحظر، regex البحث).
  - المسار B: أنبوب الـ accessibility (استنساخ Parcel، 29 محللاً، بوابة كلمة السر، الإيماءات).
  - المسار C: مستوى الأوامر (التوقيع الغائب)، عقد القواعد، الإبقاء الحي، والغيابات المثبتة.

## 3. ملخص بوابات الجودة وحدود الإثبات

1. **طوبولوجيا المنظومة:** تطبيقا Qustodio منفصلان كلياً — الأهل (Cordova/React، غطاه تقرير الجولة الأولى) والطفل (أصلي Kotlin، هذا الجرد)؛ السحابة هي الوسيط الوحيد [VERIFIED].
2. **قواعد البيانات:** لا Room تجارياً للميزات — التخزين SharedPreferences (`utils/n.java` بمفاتيح `com.qustodio.qustodioapp.*` مثل `IS_ACCOUNT_CONFIGURED`، `LAST_START_SERVICE`)؛ `database/` يحوي محوّلات Gson فقط [VERIFIED].
3. **حدود الإثبات الملزمة:** لا يُدَّعى تحقق توقيع الأوامر (الحقل موجود والتحقق غائب — مثبت بالقراءة)؛ عناوين API الدقيقة غير مرصودة statically (الإعداد مشفّر) — تُذكر كـ Partial لا كحقيقة.
4. **الأمانة العلمية:** كل نتيجة موسومة `[VERIFIED]` (قُرئ الكود) أو `[INFERENCE]` (مستنتجة)؛ الغيابات (صفر DevicePolicyManager، صفر طلب إعفاء بطارية، صفر ذكاء على الجهاز، صفر WebSocket) مثبتة بالبحث الشامل لا بالافتراض.

> **ملاحظة:** ملف `sources.json` (13M) يبقى محلياً لتعذر دفعه عبر حد GitHub API (4MB) — قابل لإعادة التوليد حتمياً من الأشجار المحلية عند الحاجة.
