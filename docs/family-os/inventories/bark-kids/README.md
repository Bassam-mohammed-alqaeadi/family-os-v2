# ملف إرشادات وتوثيق جرد تطبيق Bark Kids — عائلتي (Family OS)

> **معرّف التطبيق:** `bark-kids`
> **الحزمة المفحوصة:** `com.pt.bark` (Bark Kids v7.26.0 / vc911 — Kotlin أصلي)
> **البنية المعمارية:** وكيل إنفاذ أحادي الـ APK على جهاز الطفل — Accessibility + VPN مزدوج، **بلا DeviceAdmin**
> **المرحلة:** سلسلة التوثيق العميق للخطة الموحدة #3 (Unified-Plan deep-doc series #3)
> **حالة الاعتماد:** مكتمل ومحقق — أول جرد يوثق ذكاءً اصطناعياً حقيقياً على الجهاز 🎯

> **فخر هذا الجرد:** من بين كل تطبيقات المرجع، Bark Kids هو الوحيد الذي يشحن **ONNX Runtime أصلياً
> مع 3 نماذج تصنيف** (صور إباحية + 12 فئة احتيال نصي + رسائل OTP قصيرة). هذا الجرد يفكك تلك
> المنظومة بالكامل — الحزم الأصلية، النماذج، خطوط المعالجة، العتبات، المحفزات، وصيغ النتائج —
> وهو التحقق العملي الوحيد لمعمارية Family OS "ذكاء خفيف على الجهاز + وكيل خادمي".

## 3. ملخص بوابات الجودة وحدود الإثبات

1. **الذكاء على الجهاز حقيقي ومفكك:** 3 نماذج (16.1MB صور + 16.8MB نصوص + 49KB OTP) + ONNX Runtime لكل ABI — كل العتبات والصيغ والمحفزات موثقة بأرقام الأسطر.
2. **نموذج النصوص بلا مستدعٍ داخلي:** مثبت بالبحث الشامل في smali (مرجعان ذاتيان فقط) — التنفيذ في تطبيق `us.bark.guarddog` الرفيق عبر بثوث الاحتيال.
3. **بلا DeviceAdmin:** الإنفاذ = Accessibility (مضاد عبث + كشط ~57 مساعداً) + VPN (نفق أصلي + أحكام DNS خادمية) — لا سياسات إدارة أجهزة.
4. **حدود الإثبات الملزمة:** الغيابات (صفر تحميل نماذج، صفر DeviceAdmin) مثبتة بالبحث الشامل لا بالافتراض؛ كل نتيجة موسومة `[VERIFIED]` أو `[INFERENCE]`.
5. **الأمانة العلمية:** الأنماط المرفوضة أمنياً (مفاتيح مكتوبة صراحة، `DEBUG_PASSWORD_BYPASS_ENABLED`، فترة سماح التثبيت) موثقة في `BKK-RES-000018` — لا تُنسخ.

> **ملاحظة:** ملف `sources.json` (17M) يبقى محلياً لتعذر دفعه عبر حد GitHub API (4MB) — قابل لإعادة التوليد حتمياً من الأشجار المحلية عند الحاجة.
