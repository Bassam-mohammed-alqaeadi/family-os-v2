# ملف إرشادات وتوثيق جرد تطبيق Quizlet — عائلتي (Family OS)

> **معرّف التطبيق:** `quizlet`
> **الحزمة المفحوصة:** `com.quizlet.quizletandroid` v10.58 (تطبيق واحد — لا نسخة طفل)
> **البنية المعمارية:** عميل نحيف + خادم ذكي (thin client / smart server)
> **المرحلة:** سلسلة التوثيق العميق للخطة الموحدة #3 (Unified-Plan deep-doc series #3)
> **حالة الاعتماد:** مكتمل ومحقق 🎯

> **حسم هذا الجرد:** تقرير الجولة الأولى ترك سؤالًا مفتوحًا — «الحساب الفعلي للفترات لم أعثر عليه
> (غالبًا في الخادم أو داخل oldlearn المشوش)». هذا الجرد **يغلقه نهائيًا**: بحث شامل في 23,433 ملفًا
> يثبت **صفر حساب جدولة على العميل** — SRS خادمية 100% عبر `POST https://api.quizlet.com/3.11/srs/status`.
> القيمة المستخرجة هي **العقود** (SrsRequest، حلقة الخطوات، تخزين الاستحقاق)، لا الخوارزمية.

## 3. ملخص بوابات الجودة وحدود الإثبات

1. **الحسم المركزي:** الجدولة خادمية؛ العميل يعرض خطوات SDUI ويخزن `dueTimestampSec` — لا تُطلب دورة استخراج أخرى للصيغة.
2. **أنظف العقود:** `studiablemodels` (أسئلة/تصحيح/تقدم) و`SrsRequest` وحقول `StudySet` — جاهزة للنسخ.
3. **حدود الإثبات:** الغيابات (صفر جدولة عميلة، صفر لوحة صدارة، صفر XP) مثبتة بالبحث الشامل لا بالافتراض؛
   الميكانيكا المشوشة موسومة B/جزئية ولا تُبنى عليها خطط حرفية.
4. **التخزين:** كل شيء محلي (`local_only`) — لا دفعات GitHub في هذه المهمة.

> **ملاحظة:** ملف `sources.json` (35M) يبقى محلياً لتعذر دفعه عبر حد GitHub API (4MB) — قابل لإعادة التوليد حتمياً من الأشجار المحلية عند الحاجة.
