# ملف إرشادات وتوثيق جرد تطبيق FamiSafe — عائلتي (Family OS)

> **معرّف التطبيق:** `famisafe`
> **الحزمتان المفحوصتان:** `com.wondershare.famisafe` (الأب) + `com.wondershare.famisafe.kids` (الطفل / Fammy)
> **البنية المعمارية:** منظومة ثنائية التطبيق (Dual-App Ecosystem) — وحدة تحكم الأب + وكيل إنفاذ الطفل
> **المرحلة:** سلسلة التوثيق العميق للخطة الموحدة #1 (Unified-Plan deep-doc series #1)
> **حالة الاعتماد:** مكتمل ومحقق — أول جرد لتطبيق طفل على الإطلاق 🎯

> **فخر هذا الجرد:** كل الجرود السابقة (بما فيها فرع `feat`) غطت تطبيقات الأهل فقط. هذا أول جرد في البرنامج يحلل **تطبيق الطفل** (`com.wondershare.famisafe.kids`) — حيث يعيش الإنفاذ الحقيقي: الحظر، مضاد العبث، التصفية، والسياج الجغرافي.

## 1. الفهرس والوثائق الهندسية المعتمدة في مجلد التحليل (`analysis/`)

تستقر كافة وثائق التحليل الهندسي المعمق في مجلد [`analysis/`](./analysis/) وفق المعيار المعماري الموحد لبرنامج BIP:

- **وثيقة الاستكشاف الوظيفي وتحليل الفجوات:** [`analysis/COVERAGE-AND-GAPS.md`](./analysis/COVERAGE-AND-GAPS.md)
  - تغطية 44 وظيفة تفصيلية موزعة عبر 11 مجالاً وظيفياً (أب + طفل):
    - **33 وظيفة مؤكدة بالكود (Confirmed — Level A):** ترميز الجداول، الحظر بالطبقة، الدفاعات التسع، مستوى الأوامر.
    - **7 وظائف مشتقة (Derived — Level B):** حظر الجهاز الكامل، القائمة البيضاء، إلغاء الربط.
    - **2 وظيفة جزئية (Partial):** لقطة الشاشة عن بُعد، التسجيل الصوتي المحيطي (أوامر بلا تأكيد تنفيذ).
    - **2 وظيفة غير موجودة (Not Found):** ذكاء اصطناعي على الجهاز (صفر)؛ بوابة كلمة سر لمنع إلغاء التثبيت.
- **تقرير التشريح البنيوي والمكونات (T1):** [`analysis/T1-STRUCTURAL-REPORT.md`](./analysis/T1-STRUCTURAL-REPORT.md)
  - تشريح Manifest الأب (415 سطراً: 129 نشاطاً، 21 خدمة، 14 مستقبلاً، 8 مزودين، 37 إذناً) وManifest الطفل (408 أسطر: AccessibilityService + DeviceAdmin + خدمات الإبقاء الحي + 5 واجهات حظر).
  - حسم طوبولوجيا المنظومة الثنائية وإثبات غياب أي قناة مباشرة أب↔طفل.
  - حصر 175 دالة API للأب (smali) ونقاط الطفل (سحب القواعد، حكم الويب، رفع الموقع).
- **خريطة الموارد المعمارية (T2):** [`analysis/T2-RESOURCE-MAP.md`](./analysis/T2-RESOURCE-MAP.md)
  - توثيق 18 مورداً معمارياً ووظيفياً من `FS-RES-000001` إلى `FS-RES-000018` + 14 علاقة بينية (`REL-000048` إلى `REL-000061`).
- **التحليلات الهندسية المعمقة (T3):** [`analysis/T3-ENGINEERING-DEEP-DIVES.md`](./analysis/T3-ENGINEERING-DEEP-DIVES.md)
  - المسار A: فك ترميز `ScreenTimeTool` بالكامل ونموذج توزيع `ControlsBean` سحابياً.
  - المسار B: سياسة "لا قتل أبداً" للحظر بالطبقة وبطارية مضاد العبث (9 دفاعات + `lockNow`).
  - المسار C: مستوى أوامر FCM+WebSocket (30 فعلاً)، تصفية الويب بحكم خادمي، السياج الجغرافي المخصص بلا Google، والغياب المثبت للذكاء على الجهاز.

## 3. ملخص بوابات الجودة وحدود الإثبات

1. **طوبولوجيا المنظومة الثنائية:** الحزمتان بإصدار موحد (9.1.7.1023) — الأب يحرر القواعد والطفل ينفذها؛ السحابة هي الوسيط الوحيد.
2. **قواعد البيانات:** لا جداول علائقية تجارية في أي من التطبيقين — التخزين SharedPreferences بصيغة JSON (`controls_init_v5`، `sp_appusetime_record`، `geofence_check_time`).
3. **حدود الإثبات الملزمة:** لا يُدَّعى تنفيذ أمر على جهاز الطفل لمجرد إرساله من الأب — التوصيل عبر FCM/WebSocket التالي غير محسوم التوقيت (Level C).
4. **الأمانة العلمية:** كل نتيجة موسومة `[VERIFIED]` (قُرئ الكود) أو `[INFERENCE]` (مستنتجة)؛ الغيابات (صفر ذكاء على الجهاز، صفر قتل تطبيقات) مثبتة بالبحث الشامل لا بالافتراض.

> **ملاحظة:** ملف `sources.json` (فهرس 118,621 ملفاً، 67MB) يبقى محلياً لتعذر دفعه عبر حد GitHub API (4MB) — وهو قابل لإعادة التوليد حتمياً من الأشجار المحلية عند الحاجة.
