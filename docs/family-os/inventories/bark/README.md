# ملف إرشادات وتوثيق جرد تطبيق Bark — عائلتي (Family OS)

> **معرّف التطبيق:** `bark`
> **الحزمتان المفحوصتان:** `cm.pt.barkparent` (الأب — React Native 6.5.1) + `com.pt.bark` (الطفل — Kotlin أصلي 7.26.0)
> **البنية المعمارية:** منظومة ثنائية التطبيق (Dual-App Ecosystem) — أب هجين (RN + Fabric) + وكيل طفل أصلي بذكاء على الجهاز
> **المرحلة:** سلسلة التوثيق العميق للخطة الموحدة (Unified-Plan deep-doc series)
> **حالة الاعتماد:** مكتمل ومحقق

> **فخر هذا الجرد:** أول توثيق في البرنامج **لذكاء اصطناعي حقيقي على الجهاز** — نماذج ONNX مشحونة بأوزانها
> (`adultmediamobile` للصور البالغة + `mobilemodel` لتصنيف النصوص + مصنّف احتيال TF-IDF)،
> مع فك كامل لخط الاستدلال (tokenize → tensors → softmax → عتبة 0.97) وخط الإقران برمز الجهاز.

## 1. الفهرس والوثائق الهندسية المعتمدة في مجلد التحليل (`analysis/`)

تستقر كافة وثائق التحليل الهندسي المعمق في مجلد [`analysis/`](./analysis/) وفق المعيار المعماري الموحد لبرنامج BIP:

- **وثيقة الاستكشاف الوظيفي وتحليل الفجوات:** [`analysis/COVERAGE-AND-GAPS.md`](./analysis/COVERAGE-AND-GAPS.md)
  - تغطية وظيفية موزعة عبر الأب والطفل:
    - **وظائف مؤكدة بالكود (Confirmed — Level A):** جسر RN (20 حزمة)، الإقران برمز الجهاز، REST v2 (16 نقطة + 3 مضيفين)، مفردات `BarkBroadcasts`، دفع "الانتباه"، خط الرفع `ServerUpdate`، محرك ONNX (12 تسمية/عتبة 0.97)، الثنائية VPN+Accessibility، NitroIAP، البصمة.
    - **وظائف مشتقة (Derived — Level B):** رابط GraphQL للأب، توليد رمز الجهاز أبوياً، التصنيف التنبيهي خادمي.
    - **وظائف جزئية (Partial):** شاشات لوحة الأب (الحزمة minified)، قائمة عمليات GraphQL.
    - **وظائف غير موجودة (Not Found):** ذكاء على الجهاز في الأب (صفر)؛ قناة مباشرة أب↔طفل (صفر)؛ DeviceAdmin في الطفل (صفر).
- **تقرير التشريح البنيوي والمكونات (T1):** [`analysis/T1-STRUCTURAL-REPORT.md`](./analysis/T1-STRUCTURAL-REPORT.md)
  - تشريح manifest الأب (418 سطراً: 14 نشاطاً، 15 صلاحية وظيفية، ~140 رابطاً عميقاً) وmanifest الطفل (VPN + Accessibility + مستقبلات `exported=true`).
  - حسم طوبولوجيا المنظومة: أب RN (Hermes v98 + Fabric) وطفل Kotlin أصلي — السحابة الوسيط الوحيد.
  - حصر 20 حزمة أصلية (`PackageList.java`) و16 نقطة REST للطفل و3 مضيفين.
- **خريطة الموارد المعمارية (T2):** [`analysis/T2-RESOURCE-MAP.md`](./analysis/T2-RESOURCE-MAP.md)
  - توثيق 16 مورداً معمارياً ووظيفياً من `BKP-RES-000001` إلى `BKP-RES-000016` + 12 علاقة بينية (`REL-000300` إلى `REL-000311`).
- **التحليلات الهندسية المعمقة (T3):** [`analysis/T3-ENGINEERING-DEEP-DIVES.md`](./analysis/T3-ENGINEERING-DEEP-DIVES.md)
  - المسار A: جسر React Native — الحزم الـ 20، `RNCConfig`، حزمة Hermes، GraphQL persisted queries.
  - المسار B: الإقران برمز الجهاز — `POST login` (`password=<code>`)، بوابات القدرات، `activateConnection`، إعادة استخدام الرمز (مضاد إلغاء التثبيت).
  - المسار C: محرك الذكاء على الجهاز — النماذج الثلاثة، خط `TextAnalyzer`، تصنيف الـ 12 تسمية، `OTPClassifier`، سياسات الحذف.

## 3. ملخص بوابات الجودة وحدود الإثبات

1. **طوبولوجيا المنظومة الثنائية:** الأب (6.5.1) لوحة تحكم RN خالصة بلا إنفاذ؛ الطفل (7.26.0) وكيل أصلي (VPN + Accessibility + ONNX)؛ السحابة الوسيط الوحيد.
2. **الذكاء على الجهاز:** مثبت بالملفات والكود — 3 نماذج (`res/raw/`) + `libonnxruntime.so` + خط `us.bark.sdk.analysis` الكامل؛ العتبة 0.97 والتصنيفات الـ 12 مقروءة حرفياً.
3. **حدود الإثبات الملزمة:** رابط GraphQL للأب وقائمة عملياته غير مستخرجة (تشفير/minify) — موسومة `غير محسوم` لا يُبنى عليها.
4. **الأمانة العلمية:** كل نتيجة موسومة `[VERIFIED]` (قُرئ الكود) أو `[INFERENCE]` (مستنتجة)؛ الغيابات (صفر ذكاء في الأب، صفر قناة مباشرة، صفر DeviceAdmin في الطفل) مثبتة بالبحث الشامل.

> **ملاحظة:** ملف `sources.json` (33M) يبقى محلياً لتعذر دفعه عبر حد GitHub API (4MB) — قابل لإعادة التوليد حتمياً من الأشجار المحلية عند الحاجة.
