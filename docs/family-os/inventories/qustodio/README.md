> **معرّف التطبيق:** `qustodio`
> **الحزمة المفحوصة:** `com.qustodio.family.parental.control.app.screentime` v182.41.0 (تطبيق الأهل فقط)
> **البنية المعمارية:** عميل سحابي هجين (Cordova + React SPA) — لوحة تحكم الأهل بلا أي إنفاذ على الجهاز

## 3. ملخص بوابات الجودة وحدود الإثبات

1. **طوبولوجيا العميل السحابي:** تطبيق الأهل عميل REST خالص — القواعد تُحرَّر في React وتُدفَع عبر `PUT`،
   والطفل (`com.qustodio.qustodioapp`, منفصل) يُبلَّغ عبر FCM؛ السحابة هي الوسيط الوحيد.
2. **قواعد البيانات:** لا جداول علائقية — التخزين localStorage فقط (بما فيها الرموز بنص صريح — مرفوض أمنياً).
3. **حدود الإثبات الملزمة:** المفردات السبع قُرئت من مفسّر الطفل (نظرة مصرح بها لعقد الأوامر)؛
   منطق تنفيذ الطفل المشوَّش خارج النطاق الأبوي ومُسجَّل كفجوة.
4. **الأمانة العلمية:** كل نتيجة موسومة `[VERIFIED]` (قُرئ الكود) أو `[INFERENCE]` (مستنتجة)؛
   الغيابات (صفر ذكاء، صفر QR، صفر WebSocket، صفر SQLite، `onboarding_token` الميت) مثبتة بالبحث الشامل لا بالافتراض.
5. **تصحيح الجولة الأولى:** مخطط الروابط العميقة الفعلي `qustodiofamily://` (لا `qustodio://`)؛
   "المنطق لم يُحلل" أصبح محللاً سطراً بسطر عبر خرائط المصدر.

> **ملاحظة:** ملف `sources.json` (22M) يبقى محلياً لتعذر دفعه عبر حد GitHub API (4MB) — قابل لإعادة التوليد حتمياً من الأشجار المحلية عند الحاجة.
