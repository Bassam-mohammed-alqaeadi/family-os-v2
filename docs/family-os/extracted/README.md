# الملفات المستخرجة — الفهارس والبصمات

بقرار المستخدم (2026-11-04، سياسة "الفهارس فقط"): الأشجار الكاملة لمخرجات التفكيك
(~6GB في `~/workspace/rework/`) تبقى محلياً، وهذا المجلد يحتفظ بالفهارس الموثقة في المستودع.

## محتويات هذا المجلد
- `summary-<app>.md`: ملخص مقروء لكل تطبيق — عدد الملفات، الحجم الإجمالي،
  إصدار التطبيق، إصدارات الأدوات (apktool/jadx)، وتاريخ التوليد.

## الفهارس الكاملة (SHA256 لكل ملف)
الفهارس الكاملة (`manifest-<app>.sha256` — بصيغة `<sha256>  <size>  <relative-path>`)
تغطي ~611k ملف (~83MB) ولا يمكن دفعها عبر GitHub API من هذه البيئة
(حدود حجم الطلب)، لذا تبقى مع الأشجار المحلية.

## إعادة توليد الفهارس الكاملة
```bash
cd ~/workspace/tools/family-os && python3 generate_manifests.py
```
يُعيد إنشاء `manifest-<app>.sha256` في ~5 دقائق من الأشجار المحلية في `~/workspace/rework/`.
