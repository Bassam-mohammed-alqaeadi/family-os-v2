# الملفات المستخرجة — الفهارس والبصمات

بقرار المستخدم (2026-11-04): الملفات الضخمة لمخرجات التفكيك (~6-8GB) تبقى محليًا،
وهذا المجلد يحتفظ بالفهارس والبصمات كمرجع موثق في المستودع.

## الملفات
- `manifest-<app>.sha256` — فهرس كل ملفات التطبيق المستخرجة مع بصمة SHA256 وحجم كل ملف.
- `summary-<app>.md` — ملخص: عدد الملفات، الحجم الإجمالي، تاريخ التوليد.

## التوليد
```bash
python3 ~/workspace/tools/family-os/generate_manifests.py
```
تُنشر الفهارس هنا عند **اكتمال التفكيك** فقط — التفكيك جارٍ حاليًا في المحادثة الرئيسية.
