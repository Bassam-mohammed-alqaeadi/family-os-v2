## 4. الالتزام بحوكمة البيانات وبروتوكول الغرفة النظيفة (Clean-Room)

1. **المستوى A (Level A):** الأدلة الأصلية مباشرة من APK (`AndroidManifest.xml`, `03_decompiled_src/`, `_target_dex/`, الموارد).
2. **المستوى B (Level B):** النماذج المشتقة لـ Family OS (`04_extracted_algorithms/`, `05_data_models_and_schemas/`).
3. **المستوى C (Level C):** فرضيات مدققة تم حسمها وتطهيرها (`[PARTIAL-EVIDENCE]`).
4. **تطهير كتالوج الـ APIs:** تم استبعاد 49 مدخلاً ملوثاً بشوائب HTML/XML وتأسيس الكتالوج على الثوابت البرمجية الحقيقية لخوادم `api.familywall.com`.
