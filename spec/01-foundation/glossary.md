# المصطلحات

استخدم الاسم الإنجليزي (المعرّف) في الكود والواجهات البرمجية، والاسم العربي في النصوص والشاشات. لا تخترع مصطلحات بديلة.

| العربي | المعرّف | التعريف |
|---|---|---|
| العائلة | family | الوحدة الأساسية: مجموعة أفراد تحت مالك واحد. |
| المالك | owner | فرد العائلة ذو الصلاحية الكاملة (الأب). فرد واحد لكل عائلة، ونقل الملكية صلاحية خاصة به. |
| الفرد | member | أي شخص في العائلة، له حساب وملف وصلاحيات. |
| المسمى | title | وصف عرضي يحدده المالك للفرد (أب، أم، جد، عم، مربية...). لا يحدد الصلاحيات. |
| ملف الفرد | member_profile_type | adult أو child، يحدد خضوعه للرقابة واستحقاقه للمكافآت. |
| الفئة العمرية | age_band | young_child (حتى 6)، child (7 إلى 12)، teen (13 إلى 17)، adult (18 فأكثر). |
| الصلاحية | capability | حق محدد بالصيغة domain.action مثل rewards.manage. |
| مجموعة الصلاحيات | permission_set | قائمة صلاحيات مسماة يمنحها المالك لفرد مع نطاق. |
| النطاق | scope | على من تسري الصلاحية: all_members أو specific_members أو children_only أو self. |
| التفويض | delegation | منح المالك صلاحيات لفرد، مع مدة اختيارية. |
| المتحكم | controller | أي فرد يملك صلاحية تحكم على فرد آخر (المالك أو مفوَّض). |
| التحكم | control | إعداد واحد قابل للضبط له نوع وقيمة وأثر فعلي. |
| سطح التحكم | control_surface | كل ما يخص التحكم في نظام: الجرد، القوالب، اللوحة، الصلاحيات، السجل. |
| القالب الجاهز | preset | مجموعة قيم تحكم جاهزة تُطبَّق بنقرة. |
| القيمة الفعالة | effective_value | القيمة الناتجة بعد حسم كل الطبقات. |
| الاستثناء | exception | منحة مؤقتة فوق القيمة الفعالة (مثل وقت شاشة إضافي بمدة). |
| طلب الموافقة | approval_request | طلب من فرد (غالبًا الطفل) إلى المتحكمين. |
| مركز القيادة | command_center | الشاشة الرئيسية للمتحكم تجمع لوحات كل الأنظمة. |
| مركز الإعدادات | settings_hub | بوابة كل الإعدادات بحسب الفرد أو بحسب الميزة. |
| الودجت | widget | عنصر لوحة صغير يعرض بيانات وإجراءً سريعًا. |
| الوحدة | module | مكوّن مستقل يسجّل لوحاته وإعداداته في المنصة. |
| حزمة المحتوى | content_pack | محتوى قابل للإضافة (ديني، تعليمي، لغة) دون تغيير الكود. |
| الخطة | plan | مستوى الاشتراك: free أو family أو premium أو ai. |
| الاستحقاق | entitlement | ميزة أو حد تتيحه الخطة. |
| عملة العائلة | family_coin | وحدة المكافآت التي يحددها الأب للأطفال. |
| المهمة | task | عمل يُكلَّف به فرد، ويكسب منه الطفل العملة. |
| متجر الجوائز | reward_store | قائمة جوائز يحددها المالك يشتريها الطفل بالعملة. |
| حدث التدقيق | audit_event | سجل غير قابل للتعديل لتغيير حدث. |
| وضع الأسرة | family_mode | تطبيق التحكم العميق على جهاز أندرويد للطفل (المرحلة 2). |
| الربط بجهاز | pairing | ربط جهاز الطفل بحسابه بموافقة المتحكم. |
| شاشة الشفافية | transparency_screen | شاشة يرى فيها الفرد ما الذي يُراقَب أو يُقيَّد. |
| حالة التوفر | availability_state | الحالة الحقيقية لتحكم: active وغيرها (انظر معمارية التحكم). |
