# رموز الألوان (Color Tokens)

> الحالة: معتمد للتنفيذ | القرارات: D-016 | يعتمد على: brand-and-logo.md §2 | يُولَّد منه: `packages_dart/fos_design_system`
> الألوان الخمسة للشعار: **1F3A6B** (كحلي)، **1F6B3B** (أخضر)، **CF5B2C** (برتقالي)، **C8A24A** (ذهبي)، **FCFAED** (كريمي).

## 1. البنية: ثلاث طبقات
1. **Primitive (خام):** قيم الألوان ودرجاتها. لا تُستخدم مباشرة في الواجهة.
2. **Semantic (دلالي):** أدوار (`surface`, `primary`, `success`...). هذه ما تستخدمه المكوّنات.
3. **Component (مكوّن):** رموز خاصة بمكوّن عند الحاجة (`button.primary.bg`).
- **القاعدة:** لا لون بقيمة مباشرة في أي ويدجت (lint). الوضع الفاتح/الداكن وملفات التجربة تتبدل عبر الطبقة الدلالية فقط.
- **التنسيق:** JSON وفق معيار Design Tokens، ويُولَّد منه ثيم Flutter (`ThemeExtension`) تلقائيًا.

## 2. الألوان الخام (Primitive)
### 2.1 درجات العلامة
| الاسم | الدرجة الرئيسية (500/600) | ملاحظة |
|---|---|---|
| `navy` | **#1F3A6B** | الأساس. الدرجات 50-900 تُشتق بتدرج في فضاء OKLCH بثبات الصبغة |
| `green` | **#1F6B3B** | |
| `orange` | **#CF5B2C** (500)، **#B24E24** (700 للنص/الضغط) | 700 مقاسة بتباين ≈ 5.2:1 مع الأبيض |
| `gold` | **#C8A24A** | يُستخدم زخرفة/تمييزًا، ليس نصًا على الفاتح |
| `cream` | **#FCFAED** | سطح الأساس الفاتح |
- **التوليد:** سلم من 11 درجة (50، 100، ... 900، 950) لكل لون بأداة موثقة في `tools/`، وتُلتزم القيم الناتجة في ملف الرموز، ولا تُعدَّل يدويًا بلا قرار.
- **محايدات (Neutrals):** سلم رمادي دافئ مشتق من الكريمي والكحلي (ليس رماديًا باردًا) من 0 إلى 950، ونص رئيسي مشتق من كحلي داكن بدل الأسود النقي.

### 2.2 ألوان الحالة (خارج الباليت، بدرجات متناسقة)
| الدور | القاعدة |
|---|---|
| **Success** | يعتمد الأخضر 1F6B3B |
| **Warning** | عنبري دافئ متناسق مع البرتقالي ولا يماثله (يُفرَّق بالأيقونة) |
| **Danger** | أحمر معتدل التشبع، واضح التمييز عن البرتقالي |
| **Info** | أزرق مشتق من الكحلي بإضاءة أعلى |
- لا يعتمد المعنى على اللون وحده (accessibility §2.1).

## 3. الأدوار الدلالية (Semantic)
### 3.1 الوضع الفاتح
| الدور | القيمة |
|---|---|
| `surface.base` | cream (#FCFAED) |
| `surface.raised` | أبيض دافئ (سطح بطاقة) |
| `surface.sunken` | محايد 50 دافئ |
| `surface.inverse` | navy 900 |
| `text.primary` | navy 900 (≈ تباين عالٍ مع الكريمي) |
| `text.secondary` | navy 700 أو محايد 700 |
| `text.disabled` | محايد 400 |
| `text.on-primary` | أبيض / cream |
| `primary.default` | **navy #1F3A6B** |
| `primary.hover/pressed` | navy أغمق |
| `accent.attention` | orange 500 (زخرفة/أيقونات/نص كبير) |
| `accent.attention-strong` | orange 700 (نص صغير/أزرار نصية) |
| `accent.reward` | gold #C8A24A (زخرفة وخلفية، النص عليها كحلي) |
| `success.default` | green #1F6B3B |
| `border.default / subtle / strong` | محايد دافئ |
| `focus.ring` | navy أو أزرق فاتح بتباين ≥ 3:1 وسمك 2dp |
### 3.2 الوضع الداكن
- خلفيات مشتقة من الكحلي العميق (ليس أسود نقيًا): `surface.base` ≈ navy 950، `surface.raised` ≈ navy 900-800.
- النص: كريمي/محايد فاتح (لا أبيض نقي)، الثانوي بدرجة أخف.
- الأخضر والبرتقالي والذهبي تُرفع إضاءتها لتحتفظ بتباين ≥ 4.5:1 على الخلفية الداكنة (الذهبي ينجح هنا كنص).
- الوضع الداكن **ليس عكسًا حرفيًا**، ويُصمَّم ويُختبر مستقلًا (golden).

## 4. التباين المحسوب (إلزامي، مرجع للتصميم)
| الزوج | التباين التقريبي | الحكم |
|---|---|---|
| كحلي على كريمي | ≈ **10.7:1** | ✔ AAA |
| أخضر على كريمي | ≈ **6.2:1** | ✔ AA |
| أبيض على كحلي | ≈ **11.2:1** | ✔ AAA |
| أبيض على أخضر | ≈ **6.5:1** | ✔ AA |
| كحلي على ذهبي / ذهبي على كحلي | ≈ **4.65:1** | ✔ AA (نص عادي) |
| أبيض على برتقالي 500 | ≈ **4.05:1** | ✘ للنص الصغير، ✔ للنص الكبير (≥ 18.5px عريض أو 24px) والأيقونات |
| أبيض على برتقالي 700 (#B24E24) | ≈ **5.2:1** | ✔ AA |
| برتقالي 500 على كريمي | ≈ **3.86:1** | ✘ نص صغير، ✔ مكوّنات/نص كبير |
| ذهبي على كريمي | ≈ **2.3:1** | ✘ لا نص ولا حدود مكوّن، زخرفة فقط |
- **قواعد مشتقة:**
  1. زر أساسي: خلفية كحلي ونص أبيض.
  2. زر مميز (Accent): خلفية برتقالي 700 ونص أبيض، أو برتقالي 500 بنص كبير عريض فقط.
  3. الذهبي لا يُستخدم نصًا ولا حدّ مكوّن على الفاتح؛ يُستخدم نصًا على الكحلي أو زخرفة/أيقونة مكافأة مع نص مرافق.
  4. أي تركيبة جديدة تمر باختبار تباين آلي في CI (يفشل دون AA).
- الأرقام تقريبية بحسب معادلة WCAG، ويثبّتها الاختبار الآلي (DS-CL-01) بقيم دقيقة.

## 5. الألوان لكل ملف تجربة
نفس الباليت، مع **أوزان** مختلفة (role-experience-model §9):
| الملف | سطح أساسي | تمييز | ملاحظة |
|---|---|---|---|
| command/supervisor | cream + بطاقات بيضاء | كحلي + ذهبي رفيع | لوحات كثيفة هادئة |
| adult | cream | كحلي + أخضر | دفء وهدوء |
| teen | cream/داكن | كحلي + أخضر + لمسات برتقالي | حيوية متوسطة |
| child | cream دافئ مع خلفيات ملوّنة | برتقالي + أخضر | تباين أعلى وأشكال مستديرة |
| young_child | خلفيات نقية | ألوان مشبعة عالية التباين | أيقونات كبيرة |
- كل ملف يختار **ثيمًا** (`ThemeProfile`) يعيد تعيين الأدوار الدلالية، لا الخام.

## 6. ألوان الحالات والتنبيهات (معاني ثابتة عبر التطبيق)
| المعنى | اللون | الأيقونة المرافقة |
|---|---|---|
| آمن/نجاح/متصل | أخضر | علامة صح/درع |
| انتباه/إجراء مطلوب | برتقالي/عنبري | تنبيه/نقطة |
| خطر/طارئ/SOS | أحمر | تحذير/جرس |
| معلومة | أزرق | معلومة |
| مكافأة/إنجاز | ذهبي | نجمة/كأس |
| معطّل/غير متاح (D-018) | محايد + شرح | قفل/شرطة |
- حالات التوفر (`unavailable_on_device`, `requires_upgrade`, `not_delegated`...) لها أنماط مرئية موحدة (states-empty-loading-error.md).

## 7. الخرائط وتصوّر البيانات
- خرائط الموقع: نمط خريطة فاتح/داكن بتنسيق متسق مع الباليت، وعلامات الأفراد بلون تعريفي لكل فرد (من لوحة مخصصة لا تتعارض مع ألوان الحالات).
- **لوحة ألوان تعريف الأفراد:** 8-12 لونًا متباعدًا مميزًا لعمى الألوان، ويظهر معها أحرف/أيقونة.
- المخططات: لوحة تسلسلية وفئوية آمنة لعمى الألوان، مع أنماط وتسميات مباشرة.

## 8. الاستخدام في الكود
- `Theme.of(context).fos.colors.surfaceBase` (امتداد ثيم)، ولا `Color(0xFF...)` خارج حزمة التصميم.
- توليد: `pnpm gen:tokens` → JSON → Dart (`fos_design_system`) + وثيقة HTML للمعاينة (swatches مع التباين).
- تغيير رمز يمر بمراجعة تصميم، ويشغّل golden وتباين لكل المكوّنات.

## 9. معايير القبول
1. DS-CL-01: اختبار تباين آلي يتحقق من كل أزواج (نص/سطح) و(أيقونة/سطح) بكلا الوضعين، ويفشل دون AA (3:1 للمكوّنات والنص الكبير).
2. DS-CL-02: لا لون مباشر خارج `fos_design_system` (lint).
3. DS-CL-03: الدرجات المولّدة من الألوان الخمسة ثابتة (snapshot) ولا تتغير بلا قرار.
4. DS-CL-04: الوضع الداكن مصمم ومختبر بـ golden لكل مكوّن.
5. DS-CL-05: كل حالة دلالية (نجاح/خطر/...) لها أيقونة أو نص مرافق (لا لون فقط).
6. DS-CL-06: لوحة ألوان الأفراد مختبرة لعمى الألوان الثلاثة الشائعة.
7. DS-CL-07: ثيم كل ملف تجربة ينتج نفس الأدوار الدلالية دون استثناء (اختبار اكتمال).

## 10. مسائل مفتوحة
- **C-001:** قيم درجات 50-950 النهائية تُولَّد وتُثبَّت عند بناء الحزمة وتُراجَع بصريًا.
- **C-002:** قيمة الأحمر والعنبري النهائيتين بعد اختبار المشهد مع الأخضر والبرتقالي.
