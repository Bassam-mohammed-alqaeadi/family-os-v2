## 2. تفصيل حالات العرض المتكيفة لشريط التنقل (Adaptive Navigation States)

تتغير بنية شريط التنقل السفلي تلقائياً بمجرد تغيير الدور النشط دون الحاجة لإعادة تشغيل التطبيق:

### أ) نمط مركز القيادة للأب (`owner`)
```
[ 🏠 مركز القيادة ]   [ 📍 الخريطة ]   [ 💬 المحادثات ]   [ 📅 التقويم ]   [ ⚙️ الإعدادات ]
```
- **اللون الأساسي:** أزرق عميق نيلي (`#1F3A6B`) مع لمسات خضراء زمردية.
- **الشارات (Badges):** شارات حمراء ناعمة للإشعارات الحرجة والموافقات المعلقة.

### ب) نمط المراهقين (`teen` - L3)
```
[ 🚀 مساحتي ]   [ 💬 الدردشة ]   [ 🎯 المهام والجوائز ]   [ 📚 المذاكرة ]
```
- **اللون الأساسي:** كحلي داكن عصري (`#2E3856`) مع لمعان برتقالي دافئ (`#CF5B2C`).
- **المحتوى:** التركيز على الاستقلالية والألعاب التعليمية والتواصل الأخوي.

### ج) نمط الأطفال المبهج (`child` - L4)
```
[ 🌟 عالمي ]   [ 🃏 البطاقات الذكية ]   [ 🎁 مكافآتي ]   [ 📞 الأسرة ]
```
- **اللون الأساسي:** ألوان باستيل مشرقة وخلفيات مبهجة، خطوط كبيرة، وأيقونات مجسمة بديهية.
- **القفل:** غياب تام لأي مدخل للإعدادات الإدارية، وخروج يتطلب اجتياز `SCR-S1-01-03`.

## 3. مؤشرات التغذية الراجعة والاستجابة (Feedback Indicators)

1. **الاهتزاز اللمسي المخصص (Haptic Feedback System):**
   - اهتزاز خفيف جداً (Selection Click) عند التنقل بين تبويبات الشريط السفلي.
   - اهتزاز متكرر تصاعدي (Warning Pulse) أثناء الضغط المستمر على زر SOS (لمدة 3 ثوانٍ).
   - اهتزاز نجاح مضاعف (Success Buzz) عند اكتمال تفريغ طابور المزامنة غير المتصلة.
2. **الانتقالات الحركية السلسة (Micro-Interactions):**
   - حركة انزلاق أفقي ناعمة (Horizontal Slide Transition 200ms) عند تبديل شاشات الشريط السفلي.
   - تلاشي شفاف (Cross-Fade 150ms) عند تحول الثيم بين الوضع المبهج للأطفال والوضع المظلم للأب.
