## 1. عناصر الواجهة وحقول الإدخال (Input Fields)

### أ) رأس النافذة والتبديل (Header & Type Toggle)
- مفتاح اختيار النوع: `[مهمة للأبناء 📝]` | `[موعد عائلي في التقويم 📅]`.
- العنوان: «إضافة مهمة جديدة» أو «إضافة موعد عائلي».

### ب) الحقول الأساسية
- **حقل العنوان:** «عنوان المهمة أو الموعد» (مثال: حفظ سورة الملك، مراجعة الطبيب).
- **منتقي العضو المكلف (`Member Picker`):** قائمة بأفراد الأسرة لاختيار الابن أو تخصيص الموعد لكافة العائلة.
- **منتقي التاريخ والوقت (`FosDateTimePicker`):** مع إبراز اليوم الهجري والميلادي.
- **تحديد نقاط المكافأة (إذا كانت مهمة):** شريط تمرير سريع: `+5`, `+10`, `+15`, `+25` ⭐️ نقطة ذهبية.
- **محدد التكرار (`FosScheduleEditor`):** خيارات: (لا يتكرر • يومياً • أيام الدراسة الأحد-الخميس • أسبوعياً • شهرياً).

### ج) أزرار الحفظ والإلغاء
- زر `FosButton` رئيسي عريض بلون كحلي: «حفظ وإرسال للأسرة 🚀».
- زر إلغاء ناعم يعيد المستخدم لشاشته السابقة دون أي تعديل.
