## 1. عناصر الواجهة والتخطيط (UI Architecture)

### أ) رأس القناة والمعلومات الأساسية
- صورة القناة العائلية الكبيرة، اسمها، وتاريخ إنشائها.
- وصف القناة (مثال: «المجلس العائلي العام لترتيب الشؤون اليومية ومشاركة اللحظات الجميلة»).

### ب) قائمة أفراد ومشاركي القناة (Participants List)
- استعراض بطاقات الأعضاء المشاركين:
  - الأفاتار والاسم وشارة الدور (L0، L1، L3، إلخ).
  - حالة الاتصال (متصل الآن • آخر ظهور منذ 10 دقائق).
  - زر الإدارة للأب والأم: «كتم مؤقت» أو «إزالة من القناة».

### ج) خيارات التخصيص والإشعار
- **مفتاح كتم الإشعارات:** خيارات: (ساعة واحدة • 8 ساعات • دائماً).
- **عرض الرسائل المثبتة:** استعراض أرشيف الرسائل والتوجيهات المثبتة بأعلى المحادثة.

### د) الإجراءات الإدارية المشددة (للأب L0 فقط)
- زر مسح سجل الرسائل: «مسح سجل المحادثة للجميع».
- يتطلب تأكيداً نافذاً بـ `Father PIN` لتفادي الحذف العرضي للذكريات العائلية.
