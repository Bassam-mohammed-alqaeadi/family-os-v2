## 2. تفصيل الهيكل البصري لغرفة المحادثة (Chat Room Anatomy)

```
SCR-S1-08-02 (Chat Room)
│
├── 1. ChatAppBar (اسم القناة/العضو • الصورة الرمزية • مؤشر المتصلين الآن/الكتابة • زر الاتصال)
│
├── 2. MessageStreamView (قائمة تمرير عكسية فائقة السلاسة 60 FPS):
│   ├── DateDividerSticky (فاصل تاريخ اليوم / أمس)
│   ├── FosChatBubble (الرسائل المستلمة - فقاعة بيضاء ناصعة على اليمين RTL)
│   ├── FosChatBubble (الرسائل المرسلة - فقاعة كحلية/خضراء مريحة على اليسار RTL)
│   └── SystemEventMessage (رسائل النظام: انضم عضو، تم إسناد مهمة، تنبيه أمان)
│
└── 3. FosComposer (شريط الإدخال السفلي الذكي):
    ├── EmojiPickerButton (منتقي الرموز التعبيرية السريعة)
    ├── AutoGrowingTextField (حقل كتابة نصوص يتسع تلقائياً حتى 4 أسطر)
    ├── QuickChildPills (أزرار عبارات سريعة تظهر للأطفال الصغار `child`)
    └── SendButton (زر الإرسال الكحلي الدائري مع اهتزاز لمسي ناعم)
```

## 3. معايير التصميم والوصولية المطبقة
- **الألوان المعتمدة للفقاعات:**
  - رسائل المستخدم المرسلة: كحلي داكن (`#1F3A6B`) مع نص أبيض كريمي ناصع.
  - رسائل الأطفال والبراعم: إطار بلون الطفل الرمزي المعتمد في S1-02 لتمييز رسائل كل ابن بوضوح.
  - رسائل النظام التنبيهية: بطاقة وسطية رمادية ناعمة بخط مائل أنيق.
- **إمكانية الوصول (A11y):** توفير وسوم قراءة واضحة لكل فقاعة رسالة تنطق اسم المرسل، وقت الإرسال، وحالة التسليم (أُرسلت / قُرئت).
