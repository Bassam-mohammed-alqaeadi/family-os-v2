## 1. عناصر الواجهة والتخطيط (UI Architecture)

### أ) قسم الطلبات المعلقة للاعتماد (Pending Approvals)
- يظهر بأعلى الشاشة ببطاقات عريضة لكل طلب استبدال وارد:
  - اسم الطفل وصورته • الجائزة المطلوبة وتكلفتها النقطية • رصيد الطفل المتبقي بعد الخصم.
  - زران بارزان:
    - **اعتماد وصرف (أخضر):** يفتح نافذة كتابة ملاحظة شكر وتقدير للطفل.
    - **رفض أو تأجيل (رمادي/أحمر):** يطلب كتابة تعليل تربوي يظهر للطفل بلطف.

### ب) قسم كتالوج الجوائز العائلية (Family Catalog Management)
- قائمة بكافة الجوائز المعتمدة حالياً في الأسرة مع أزرار تفعيل/تعطيل سريعة.
- زر عريض: «+ إضافة مكافأة عائلية مخصصة جديدة».
  - تحديد: اسم الجائزة بالعربية، الأيقونة الممثلة، التكلفة النقطية، وتصنيف الجائزة.

### ج) قسم رعاية سلاسل الإنجاز (Streaks Care)
- استعراض بطاقة لكل طفل توضح عدد أيام سلسلته المتتالية الحالية.
- زر: «تجميد السلسلة ليوم واحد ❄️ (Streak Freeze)» للأعذار المرضية والسفر لتجنيب الطفل الإحباط.
