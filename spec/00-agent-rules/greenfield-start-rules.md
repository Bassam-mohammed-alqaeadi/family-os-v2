# قواعد البدء من الصفر

1. المستودع family-os-v2 بناء جديد بالكامل (D-002). لا يوجد كود قائم يُبنى عليه ولا يُوفَّق معه.
2. لا تستورد ولا تنسخ ولا تستلهم ملفات أو شاشات أو أكواد من أي مصدر خارج spec/. وإن وجدت على الجهاز مشاريع أو ملفات قديمة بالاسم نفسه أو بما يشبهه فتجاهلها تمامًا ولا تقرأها.
3. كل ما يُبنى يُشتق من ملفات spec وحدها.
4. أول عمل بعد التهيئة هو الخطوة 0 في execution-order.md، ثم النظام S1-01.
5. إن ورد في أي ملف spec إشارة إلى «النموذج الأولي» أو «الكود الحالي» فهي خطأ، فسجّلها في open-questions.md ولا تبحث عن مرجعها.
