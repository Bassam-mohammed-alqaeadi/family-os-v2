# سير عمل Git

- الفرع main محمي ويبقى دائمًا قابلًا للتشغيل. لا التزام مباشر عليه بعد الخطوة 0.
- فرع لكل مهمة قصيرة العمر: feat/s1-03-short-slug أو fix/s1-03-short-slug أو chore/short-slug.
- صيغة الالتزامات (Conventional Commits) مع معرّف النظام: feat(s1-03): add delegation of permissions.
- التزام صغير ومتماسك، وكل التزام يترك المشروع في حالة تعمل.
- لا يُدمج فرع إلا بعد نجاح التكامل المستمر (lint واختبارات وبناء).
- عند بلوغ نظام حالة verified يوضع وسم: s1-03-verified. وعند إغلاق مرحلة: phase-1-v0.1.0 ثم بحسب الإصدار الدلالي.
- ملف .gitignore يمنع الأسرار والملفات المولّدة. لا يُلتزم بأي ملف .env أو مفاتيح أو شهادات.
- لا إعادة كتابة لتاريخ فروع مشتركة.
- يحتفظ الوكيل بنسخة من spec/ ضمن المستودع نفسه، وتعامل تغييراتها كأي كود.
